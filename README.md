

# Student Grading Program 🎓

A simple Python program that determines a student's grade based on their score.

This is one of my beginner Python projects, created to practice **conditional statements (`if`, `elif`, and `else`)**, comparison operators, and taking user input.

## 🧠 What I Practiced

Through this project, I practiced:

* Taking user input with `input()`
* Converting input into an integer using `int()`
* Using `if`, `elif`, and `else` conditional statements
* Using comparison operators such as `>`, `>=`, and `<`
* Combining conditions using `and`
* Making decisions based on different conditions
* Writing simple and readable Python code

## 📊 Grading System

|     Score |  Grade  |
| --------: | :-----: |
|    90–100 |    A    |
|     80–89 |    B    |
|     70–79 |    C    |
|     60–69 |    D    |
|  Below 60 |    F    |
| Above 100 | Invalid |
